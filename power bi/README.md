# Power BI Visualization

The Power BI dashboard provides analysis of ASEAN foreign exchange rates sourced from the project's Gold data layer in PostgreSQL.

## Dashboard Pages

### 1. Market Summary

- High-level view of exchange rate movements across the covered ASEAN currencies.

![Market Summary](../assets/01%20-%20Market%20Summary.png)

### 2. Currency Deep Dive

- Detailed view of the currencies individually.

![Currency Deep Dive](../assets/02%20-%20Currency%20Deep%20Dive.png)

### 3. Regional Analysis

- Comparison of ASEAN currencies' performance grouped by their subregion (Maritime ASEAN / Mainland ASEAN).

![Regional Analysis](../assets/03%20-%20Regional%20Analysis.png)
